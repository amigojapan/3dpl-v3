# Skybox asset

`sunflowers_puresky_2k.jpg` is a resized copy of **Sunflowers (Pure Sky)**
from Poly Haven:

https://polyhaven.com/a/sunflowers_puresky

The original asset is released under the CC0 license. The local copy was
resized from the tonemapped 8192 x 4096 JPEG to 2048 x 1024 for faster browser
loading.
